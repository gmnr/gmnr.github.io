This is a book that has been on my to-read list for far too long.<br> Ever since
I started my coding journey (and that is circa 2015, I guess), I have always
wanted to tackle a "hands-on" programming book. Consensus on the street was,
this book would "open my eyes" on Pythonic programming.

And open my eyes it did - this books ticks all the boxes, it is very advanced,
as it tackles complex topics such as metaprogramming, but also takes your hand,
especially in the beginning when it walks you over the many ways Python handles
built-ins and fundamentals.

In the end I have truly appreciated the read, even though the topics at the end
of the books were far too advanced for a "beginner" like me.<br>However, I found
the slow burn approach to more advanced topics didactically satisfying, and
above all else, I truly felt that I have learned something.

If I ever feel my Python journey lengthening, I might give it another read.
